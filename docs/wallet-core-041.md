# Public Wallet core 0.4.1

The consumer uses `https://github.com/ZenithResearch/castalia-wallet` at
`19ec02f0000f7c59f7341f87ad4c04fd54784fe1`, the same exact core source pin as
iOS and Transfer. This pin is reachable from public Wallet main.

This is a core dependency upgrade. Existing encrypted custody, recovery,
Castaway v1/v2 identities and account descriptors retain their formats. No
account migration, replacement identity, provider trust, service enrollment or
network connection is automatic. Existing consent and origin boundaries remain
in force. Rewards packages and their database remain excluded.

Compatibility tests use disposable encrypted records generated by the actual
previous 0.3.0 runtime, in addition to existing recovery, membership, identity,
stale-write and consent tests. No real Wallet or account data is a build input.

Core grant APIs do not by themselves enable a new application grant UI or live
service access. Browser and receiver qualification remain separate release gates.
