# Working on Anima

Use native HTML, TypeScript, CSS, and Rust/WebAssembly. Do not introduce React or the Sites plugin. Preserve the accepted water, aquatic life, typography, action shapes, and native component library unless a scoped change is explicitly requested.

## Change discipline

- Inspect existing components and data models before extending them. Reuse semantic tokens and native HTML behavior.
- Edit authoring sources; regenerate `dist/`. Do not hand-edit generated pages or runtime output.
- Keep local inputs, brand foundations, and provider-issued deliverables distinct. Empty states must not fabricate activity.
- Preserve original files, reference associations, stored draft compatibility, immutable reviewed briefs, and stable request/idempotency identity.
- Keep provisional view models separate from shared contracts. Update a vendored dependency through its recorded upstream revision, with an explicit patch record and compatibility tests.

## Identity and delivery

Castalia owns custody, encryption, recovery validation, and signing. Do not implement replacement cryptography, silently create replacement identities, store private keys in cookies, or instantiate a second signer to bypass a missing integration.

Local identity, membership, authenticated session, organizational authority, transport receipt, service admission, and completion are different states. Display only what the authoritative source establishes. Fixtures must remain visibly labelled and must never be promoted to live submissions by changing a destination.

Live providers and deployment profiles are opt-in reviewed configuration. Keep the browser origin, durable intake gateway, and response projection independently configurable. Do not commit local profiles, tokens, recovery files, real briefs, uploaded originals, browser stores, private endpoints, or personal paths.

## Qualification

Run `npm ci`, `npm run build`, and `npm test` in a clean checkout. Rust requires `wasm32-unknown-unknown`. Review affected routes in the browser, including small viewports, keyboard navigation, labels, validation, focus return, reduced motion, and failure recovery. Passing unit tests is not a claim of accessibility, custody security, or live provider qualification.

Keep documentation concise and current. Record divergences and remaining integration gates in `docs/`. Preserve license notices and dependency provenance. Do not assign a project-wide license without the owner's decision.
